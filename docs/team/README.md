# 👥 Teammate Contribution Logs

This directory serves as the persistent record of each team member's contributions to the **iGOT Karmayogi (MoSPI)** project.

---

## 🎯 Purpose of Teammate Logs

Software engineering—especially during intensive hackathons like Smart India Hackathon (SIH '26)—involves significant effort that does not always appear as visible code commits in the git log.

These documents ensure that **both visible and invisible efforts** are captured and preserved for:
1. **Evaluators & Judges:** To assess individual leadership, architectural planning, and depth of domain engagement.
2. **AI Coding Agents:** To understand who owns which subsystems, what design discussions have taken place offline, and what conventions to respect.
3. **Team Members:** To maintain an ongoing record of tasks completed, decisions made, and upcoming roadmap items.

---

## 📝 What to Document

### 1. Visible Contributions (Code & Deliverables)
- Features implemented, pull requests merged, and bug fixes.
- Specific files created, modified, or refactored.
- API endpoints designed and UI routes constructed.

### 2. "Invisible" & Offline Contributions
- **Miro Flow & UX Architecture:** User journeys, wireframes, and whiteboard discussions.
- **Domain & Statistical Research:** MoSPI datasets, NSS survey documentation, UN-NQAF data rubrics, CPI formulas.
- **Prompt Engineering & AI Tuning:** System prompts, evaluation runs, and failure mode testing.
- **DevOps, Docker & Local Setup:** Debugging environment crashes, containerizing dependencies, hot-reloading configurations.
- **Team Coordination & Pitch:** Slide deck design, demo script preparation, presentation rehearsals.
